Application Android et site de présentation

Loady

Application Android qui télécharge en local les vidéos publiques de plusieurs plateformes, sans compte ni serveur, et son site de présentation.

Technologies

FlutterKotlinAstroTailwind CSS
Démo GitHub

Présentation

Loady est une application Android développée en équipe. Elle télécharge sur le téléphone les vidéos publiques de YouTube, TikTok, Instagram et d’autres plateformes, sans compte, sans serveur Loady et sans synchronisation cloud. Nous développons ensemble l’application et son site de présentation.

Fonctionnalités clés

  • Liens de huit plateformes reconnus, par collage ou partage Android.
  • Choix du format (MP4, WebM ou MP3) parmi les qualités réellement disponibles.
  • Téléchargement en arrière-plan avec notification et nouvelles tentatives en cas de coupure réseau.
  • Site de présentation avec thèmes clair et sombre et téléchargement de l’APK.

Réalisation technique

L’application est développée en Flutter, avec du Kotlin côté Android, et s’appuie sur yt-dlp pour extraire les vidéos. Le site de présentation est un site statique Astro avec Tailwind CSS, déployé sur Vercel ; son code est dans un dépôt séparé.

À savoir

Le dépôt de l’application est hébergé sur le compte d’un membre de l’équipe ; le code du site de présentation est sur github.com/dev-Chris06/loady-site. Seules les vidéos publiques sont prises en charge : les contenus protégés (DRM) sont refusés.
