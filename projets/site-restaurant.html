Le Réconfort — site de restaurant

Site vitrine présentant un restaurant de cuisine béninoise, sa carte, ses horaires et ses réservations.

Technologies

HTMLCSSJavaScript
Démo GitHub

Présentation

Le Réconfort est un projet personnel de démonstration autour d’un restaurant de cuisine béninoise à Paris. La page rassemble les informations qu’un visiteur cherche avant sa venue : découvrir la carte, voir le lieu, connaître les horaires et préparer une réservation.

Fonctionnalités clés

  • Carte affichée depuis un fichier de données séparé.
  • Galerie, horaires, accès et informations de contact réunis sur une page.
  • Formulaire de réservation qui prépare un email avec les informations saisies.

Réalisation technique

Le site est réalisé en HTML, CSS et JavaScript natif, sans framework ni étape de build. Les données de la carte sont maintenues à part puis injectées dans la page par JavaScript, ce qui permet de modifier le menu sans réécrire sa structure.

À savoir

Projet personnel de démonstration : le restaurant et ses coordonnées sont des exemples créés pour ce site. Le formulaire ouvre le logiciel de messagerie du visiteur ; aucune réservation n’est enregistrée automatiquement sur un serveur.
