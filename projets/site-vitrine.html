Bénin Tech Labs — site vitrine

Site multipage pour présenter des services de conseil IT et de développement logiciel.

Technologies

HTMLCSSJavaScript
Démo GitHub

Présentation

BÉNIN TECH LABS est un projet personnel de site vitrine pour une entreprise de conseil IT et de développement logiciel. Il présente plusieurs parcours pour découvrir les services, les projets et les contenus.

Fonctionnalités clés

  • Sept pages : Accueil, À propos, Services, Projets, Carrières, Blog et Contact.
  • Navigation adaptée au mobile et lien d’accès direct au contenu.
  • Bascule de thème clair/sombre mémorisée dans le navigateur.
  • Sections de services et de projets avec appels à l’action.

Réalisation technique

Le projet utilise HTML, CSS et JavaScript sans framework. Le thème choisi est conservé dans le stockage local du navigateur. La démo en ligne permet de parcourir les pages du site.

À savoir

Projet personnel de démonstration : le nom de l’entreprise et les contenus servent d’exemples pour ce site.
