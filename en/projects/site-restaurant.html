Le Réconfort — Restaurant Website

Restaurant website presenting Beninese cuisine, the menu, opening hours, and reservations.

Technologies

HTMLCSSJavaScript
GitHub

Overview

Le Réconfort is a personal demo project for a Beninese restaurant in Paris. The page brings together the information a visitor needs before coming in: browse the menu, see the venue, check opening hours, and prepare a reservation.

Key features

  • Menu rendered from a separate data file.
  • Gallery, opening hours, directions, and contact details on one page.
  • Reservation form that prepares an email with the visitor’s details.

Technical implementation

The site uses HTML, CSS, and vanilla JavaScript, with no framework or build step. Menu data is kept separately and rendered into the page with JavaScript, so the menu can be updated without rewriting its structure.

Good to know

Personal demo project: the restaurant and its details are examples created for this site. The form opens the visitor’s email app; it does not save reservations to a server.
